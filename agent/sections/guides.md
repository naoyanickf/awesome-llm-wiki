## Guides & references

Step-by-step walkthroughs and reference builds for standing up your own LLM Wiki. (Tutorial-style repos also appear in the tables above; these are the ones worth reading start-to-finish.)

- **[julianoczkowski/karpathy-llm-wiki](https://github.com/julianoczkowski/karpathy-llm-wiki)** — a clean step-by-step guide to building a local knowledge base from the gist.
- **[ScrapingArt/Karpathy-LLM-Wiki-Stack](https://github.com/ScrapingArt/Karpathy-LLM-Wiki-Stack)** — a build-ready reference stack for a higher-performance implementation.
- **[nanzhipro/Karpathy-llm-wiki-bootstrap-skill](https://github.com/nanzhipro/Karpathy-llm-wiki-bootstrap-skill)** — an installable skill plus a working example to bootstrap a persistent, LLM-maintained wiki.
